# 文案模板与 few-shot

本文件是本仓重写的中文模板，不复制任何 GPL/闭源仓库原文。所有输出必须是纯 JSON（结构见 `output-schema.json`）。

## 1. 标题公式

通用：`[品牌/系列] + [品类词] + [核心规格/型号] + [成色或差异点]`，总长 ≤30 字（`Array.from` 计）。

- 前 15 字放最值钱的检索词（品类词 + 型号），因为闲鱼标题在列表页会被截断。
- 不写价格、「包邮」、「特价」、「秒杀」——这些是交易条件，放描述第 4 段。
- 不用 emoji、不用「!!」「!!!」、不堆同义词。
- 型号写准：`iPhone 13 128G` 比 `苹果13 内存128` 更可检索；尺码/容量/版本必须带。

示例（都 ≤30 字）：
- `iPhone 13 128G 星光色 电池89 无维修`
- `优衣库 U系列 男款 L 白色 短袖T恤`
- `考研英语 黄皮书 2025版 有少量笔记`
- `戴森 V8 无绳吸尘器 配3吸头 功能正常`

## 2. 描述四段骨架

每段 1–3 句，段间空行；总字数 ≥30（`policy.ts` warn 阈值），建议 120–260 字。

**第 1 段 · 是什么**（结论先行）
`<品牌> <型号/规格>，<成色>，<关键属性：容量/尺码/颜色/版本>。`

**第 2 段 · 为什么出/适合谁**（真实原因）
`<出售原因>，适合<场景/人群>。<使用频率或时长>，功能<正常/异常说明>。`

**第 3 段 · 细节与瑕疵**（可验证）
`功能：<逐项>。配件：<清单或"仅主机">。瑕疵：<位置 + 现象 + 对应第几张图>。`
若含 AI 图：追加「部分图片为 AI 场景示意，实物以实拍图为准。」

**第 4 段 · 交易说明**（减少纠纷）
`<包邮/不包邮/自提>，<发货时效>，<议价规则>，<售后边界：二手非质量问题不退/支持验货>。`

标签行（紧跟第 4 段，单独一行）：
`#类目大词 #精准型号 #属性词 #场景词 #状态词`

## 3. 类目变体

### 3.1 数码 3C
- 标题：品牌 + 型号 + 容量/版本 + 电池健康或成色
- 第 1 段：国行/港版、购买年份、电池健康、维修史
- 第 2 段：换机/闲置/备用
- 第 3 段：边框磕碰、屏幕划痕、摄像头、配件（充电线/盒）
- 标签池：`#数码 #手机 #二手手机 #备用机 #学生党 #闲置 #iPhone`
- 必填：电池健康、维修史、是否解锁/有锁

### 3.2 服饰鞋包
- 标题：品牌 + 品类 + 尺码 + 颜色 + 版型
- 第 1 段：购入渠道、穿着次数、是否洗过
- 第 2 段：尺码不合/风格不合/清衣柜
- 第 3 段：实测肩宽/衣长/鞋底磨损、起球、污渍
- 标签池：`#穿搭 #闲置衣服 #通勤 #小个子 #清衣柜 #二手服饰`
- 必填：尺码、实测数据、瑕疵位置

### 3.3 图书教材
- 标题：书名 + 版次 + 划线/笔记情况
- 第 1 段：出版社、版次、是否正版
- 第 2 段：考完/毕业/重复购买
- 第 3 段：划线页数、笔记、缺页、随书光盘/激活码是否用过
- 标签池：`#二手书 #考研 #教材 #读书 #低价出 #学习资料`
- 必填：版次、划线情况；虚拟激活码必须说明已用/未用

### 3.4 虚拟资源
- 标题：资源名 + 交付形式（网盘/邮箱）+ 适用范围
- 第 1 段：内容清单与格式（PDF/视频/模板）
- 第 2 段：自用多余/整理资料
- 第 3 段：更新方式（如有）、是否含答疑、**不承诺疗效/收益/包过**
- 第 4 段：发货方式（自动发/手动发）、时效、不退不换说明
- 标签池：`#学习资料 #素材 #虚拟资源 #效率工具 #自学 #考研资料`
- 红线：不含盗版课程、破解软件、账号共享；不写「永久」「包更新」；不用「【自动发】」以外的绝对化承诺（该前缀只表示交付方式，不表示效果）

### 3.5 家居日用
- 标题：品类 + 尺寸/材质 + 风格
- 第 1 段：品牌/购入渠道、使用时长
- 第 2 段：搬家/换新/尺寸不合
- 第 3 段：承重、色差、拆装、使用痕迹
- 标签池：`#家居 #收纳 #搬家出清 #出租屋 #好物 #闲置`
- 必填：尺寸、是否可拆、是否有配件缺失

### 3.6 母婴玩具
- 标题：品类 + 适用年龄 + 安全认证/品牌
- 第 1 段：购买渠道、使用时长、消毒情况
- 第 2 段：孩子长大/重复购买
- 第 3 段：缺件、电池仓、清洗痕迹、说明书
- 标签池：`#母婴 #玩具 #绘本 #育儿 #闲置转让 #儿童`
- 必填：适用年龄、消毒方式、缺件情况

## 4. 标签构造规则

1. 恰好 5 个，格式 `#词`（无空格、无标点）。
2. 组合：1 类目大词 + 2 精准型号/属性词 + 1 场景词 + 1 状态/人群词。
3. 不与标题逐字重复 3 个以上；不造新词（错别字标签无检索量）。
4. 不蹭热点/无关大牌标签；不写「#爆款」「#低价」这类无检索意义的词。

## 6. 常见改写对照

| 原始话术 | 改写 | 原因 |
| --- | --- | --- |
| 「全网最低，错过拍大腿」 | 「价格已是最低，不议价」 | 极限词/诱导，且无法履约 |
| 「99新，无任何瑕疵」 | 「成色 95 新，边框有两处磕碰（图 3）」 | 与实物不符易纠纷 |
| 「正品保证，假一赔十」 | 「专柜购入，支持验货，非正品可退」 | 承诺需可执行 |
| 「包治百病/三天见效」 | 删除功效表述，只写成分/规格 | 医疗功效违规 |
| 「永久更新」 | 「含首次更新，后续更新另议」 | 无法履约承诺 |
