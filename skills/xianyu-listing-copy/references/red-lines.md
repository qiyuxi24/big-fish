# 红线清单

对齐 `packages/core/src/policy.ts`（`FORBIDDEN_WORDS` / `FORBIDDEN_CATEGORIES` / `POLICY_LIMITS`）。改 `policy.ts` 必须同步本文件；反之亦然。

## 1. 发布违禁词（38 条，命中即 error）

- **绝对化用语（广告法极限词）**：国家级、最高级、最佳、顶级、绝对、唯一、首个、独家、100%、纯天然、无副作用、零风险
- **金融承诺**：稳赚不赔、保证收益、高回报
- **假货/侵权术语**：高仿、复刻、原单、尾单、精仿、假冒、山寨、水货
- **医疗功效**：包治百病、根治、药到病除、治愈、抗癌、壮阳、三天见效、立竿见影
- **违禁品/黑产**：办证、代开发票、枪支、弹药、毒品、窃听器、外挂

> 描述里出现即 error；标题同样避免（`checkListing` 只查描述，但平台审核两者都看）。

## 2. 禁售/需资质类目（20 条，类目路径任一段命中即 error）

药品、医疗器械、保健食品、烟草、电子烟、枪支、弹药、管制刀具、毒品、易燃易爆、活体动物、野生动物、证件、发票、银行卡、电话卡、虚拟货币、赌博、色情、成人用品

## 3. 文案红线

1. **不虚构**：材质、尺寸、容量、配件、维修史、购买渠道、瑕疵状态，任何一项都不能编。
2. **不夸大**：不用「全新」描述有使用痕迹的商品；不用「无瑕疵」掩盖已拍出的瑕疵。
3. **不诱导**：不写「秒杀」「最后一件」「错过没了」等制造虚假紧迫感的话术。
4. **不堆砌**：标题不重复同一卖点 3 次以上；标签不蹭无关热点。
5. **不复制**：不照搬他人商品标题/描述；不把官方详情页文案整段贴过来。
6. **不用 emoji 标题**：`policy.ts` 判 warn，平台也可能误判。
7. **虚拟资源**：不写「永久」「包更新」「包过」「保收益」；不含盗版课程、破解软件、账号共享、激活码倒卖；交付方式与时效必须写清。

## 4. 图片红线

1. **主图必须实拍**：AI 图只做场景/氛围/细节补充，不能替代首图。
2. **不用他人图**：商品图、买家秀、模特图、官方详情页图都不行；不把网图喂给图生图「改一改」。
3. **不改变实物**：AI 图不得改颜色、材质、Logo、配件、磨损位置；不得新增实际没有的赠品。
4. **必须声明**：含 AI 生成/合成图时，描述第 3 段写「部分图片为 AI 场景示意，实物以实拍图为准」。
5. **首图 1:1**：正方形；建议 1024×1024 或 2048×2048。首图非方形 `checkListing` 判 warn。
6. **数量 1–9 张**：超过 9 张是 error；建议实拍在前、AI/场景图在后。
7. **格式**：PNG 优先；jpg/jpeg/heic/webp 可上传；单图大小上限待真机验证。
8. **不伪造凭证**：不生成带价格标签、质检报告、正品标识、快递面单的图片。

## 5. 版权与合规

- 不复制 GPL/AGPL 代码与 prompt 原文（XianyuAutoAgent、xianyu-auto-reply、xianyu-super-butler 只借鉴思路，见 AGENTS §1.5）。
- 不使用未授权字体/素材库图片；AI 生成图同样可能涉及训练数据版权，商用前自评。
- 保留自己拍摄的原图与 EXIF，作为盗图投诉/申诉证据。
- 平台对 AI 图尚无公开专门条款（**待验证**）；保守做法是主动声明 + 实拍主图。
